# Submission documentation

These English documents describe the implemented Privacy X-Ray snapshot and replace the earlier context-first planning drafts. They are not a record of a new team approval or a completed Devpost submission.

- [Scope](scope.md): product, evolution and boundaries.
- [Product requirements](prd.md): current default and advanced user behavior.
- [Technical specification](spec.md): architecture, real contracts and redaction semantics.
- [Delivery checklist](checklist.md): completed code validation and remaining submission work.

Start with the [project README](../README.md) for setup and demo links. Supporting material: [architecture](../docs/architecture.md), [testing](../docs/testing.md) and [recognition coverage](../docs/material-recognition.md).

The current default is **upload a local file → review detected items → select what to hide → inspect and download a PNG**. Recipient/purpose configuration is optional in the preserved advanced interface, not part of the default flow.
